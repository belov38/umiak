# umiak-sdk

Python SDK of the umiak public API (S7 §15.3). Python ≥ 3.11, httpx + attrs.

```python
from umiak_sdk import Umiak, ExitEvent

with Umiak(
    base_url="https://api.example.com", api_key="umiak_..."
) as umiak:  # or the credential chain
    sb = umiak.sandboxes.create(template="linux", labels={"session": "42"}, wait=True)
    r = sb.exec("npm test", cwd="app", timeout_seconds=600)  # stdout, stderr, exit_code
    for ev in sb.run("npm run build"):  # OutputEvent ... ExitEvent
        ...
    cmd = sb.start("python3 -m http.server 8000")  # detached
    for ev in cmd.follow(start="start"):
        ...
    sb.files.write_text("notes.txt", "hi")
    sb.files.upload("big.tar", "local/big.tar")  # 4 MiB chunks, resumable
    sb.files.download("big.tar", "copy.tar")  # Range + If-Range
    port = sb.ports.host(8000, access="public")
    for s in umiak.sandboxes.list(label={"session": "42"}):  # all pages
        ...
    sb.delete()
```

`AsyncUmiak` has the same methods as coroutines and async iterators
(`async with AsyncUmiak() as umiak`, `async for ev in sb.run(...)`). Leaving an
`async for` early keeps the HTTP stream open until the generator is
collected; wrap it in `contextlib.aclosing` to close it at once. The command
keeps running either way.

Not in the Python SDK yet (S7 decision 11): `pty` and `upload_dir`/`download_dir`.

## Behaviour

The same as `@umiak/sdk` (TS):

- **Credentials** (S7 §7.6): `api_key` / `access_token` / `token_provider`
  (called with `force` before every request; may be async for `AsyncUmiak`), then
  `UMIAK_API_KEY`, `UMIAK_ACCESS_TOKEN`, then `umiak auth token --json`. The URL is
  `base_url`, `UMIAK_API_URL` or the profile's `apiUrl` (the SDK does not read
  `/etc/umiak/config.json`: inside a sandbox with only `UMIAK_API_KEY`, set
  `UMIAK_API_URL` too); the team `team`,
  `UMIAK_TEAM` or the profile's. A profile token is never sent to another API,
  is cached until `expiresAt − 60 s`, and `401 token_expired` gets one new
  token and one repeat.
- **Idempotency-Key** (UUIDv4) on `POST /v1/sandboxes`, `/fork`, `/commands`,
  `/ptys`, `/v1/snapshots`, kept across retries.
- **Retries** (S7 §15.4): GET/HEAD/PUT/DELETE and keyed POSTs on network
  errors and 502/503/504/429; any request whose error says `retryable: true`;
  never `retryable: false`. Backoff 0.5 s × 2 up to 8 s, full jitter;
  `Retry-After` wins. Every call takes `retry_budget` (seconds, default 60).
- **Streams** (`run`, `follow`, `exec`): reattach by offset after a break, an
  `error {retryable}` frame or 45 s without data; 20 attempts in a row
  without new bytes end with the last error. `exec` keeps the last 4 MiB per
  stream. The start (POST until the command id is known) is bounded by
  `retry_budget`.
- **Errors**: `UmiakError(status, code, message, retryable, details, request_id)`;
  `status` 0 for network, credential and in-stream errors.
- **Windows fork / saved snapshot**: a running Windows sandbox is snapshotted
  only from a stopped VM. `sb.fork(...)` and `umiak.snapshots.create(...)`
  without `force_stop` raise `UmiakError` 409 `snapshot_requires_stop`
  (`details["retryWith"] == {"forceStop": True}`); `force_stop=True` stops the
  sandbox (running commands and sessions are interrupted), takes the snapshot
  and starts it again (the operation's `force_stop` reports the restart).
  Ignored for Linux and for a stopped sandbox.

API resources are the generated attrs models (`umiak_sdk.models`). Enums the
API marks `x-extensible-enum` accept unknown values (they parse as a member
named `UNKNOWN` whose `value` is the string). `umiak.raw` is the generated
client with the same transport:

```python
from umiak_sdk._gen.api.sandboxes import sandboxes_get

sb = sandboxes_get.sync("sb_...", client=umiak.raw)  # also sync_detailed; asyncio* with AsyncUmiak
```

## Layout

- `umiak_sdk/_gen`: generated by openapi-python-client from
  `apps/api/openapi/v1.json` (`openapi-python-client.yaml`, `literal_enums: false`).
- `umiak_sdk/_async`: the facade, written once for asyncio.
- `umiak_sdk/_sync`: generated from `_async` by token replacement (except `_io.py`).
- `scripts/gen.py`: regenerates both (`pnpm --filter umiak-sdk gen`); `--check`
  fails on stale files (a test runs it).

## Tests

`pnpm --filter umiak-sdk test` (through mise: `mise exec -- pnpm --filter umiak-sdk test`):
ruff, then pytest. `tests/test_facade.py` runs every scenario with `Umiak` and
`AsyncUmiak` against `apps/api` started by `tests/api_server.ts` (FakeAgent,
Postgres in docker or `UMIAK_TEST_DATABASE_URL`, a fault proxy);
`UMIAK_TEST_SKIP_PG=1` skips them. `tests/test_retry.py` needs no api.
