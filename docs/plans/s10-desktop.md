## Review focus

- An invalid action at the end of a batch does not allow input at the beginning (task 3).
- Fork/resume do not reuse streamer credentials/tickets (tasks 4–6).
- An active desktop stream blocks idle-stop both in the event and in the live recheck (task 5).
- TURN credentials do not allow relay to an arbitrary peer (tasks 5, 8).
- Screenshot metadata keeps the original screen after crop/scale; MCP uses camelCase JSON (tasks 3, 6–7).
